# WEB-LOCAL-001 — 本地服务可操作页面

## 目标

将 `http://127.0.0.1:5182/settings/voice-alignment` 做成用户可操作、可见的“本地服务”页面，而不是只读探测卡片。

## 必须交付

1. 延续“预置音色”的左列表/右详情布局；列出本地 TTS、语音对齐等服务，**不得**出现 Whisper。
2. 右详情可进入编辑状态；字段及保存必须走真实服务 API，不能伪造本地状态。
3. 顶部或列表提供新建本地服务入口，创建同样走真实 API。
4. 提供可见的预览/连通性动作：能真实调用已有服务探测或试听接口；若缺少支持编辑或预览的 API，先建立 `WEB-LOCAL-001-API-GAP.md`，只写精确接口缺口，不能用 mock 冒充完成。
5. 保持模型服务不显示 Whisper；Whisper 只在工具链页。

## 约束

- 仅处理本地服务页面及其直接 API/测试；不做其他 WebUI 基准对齐。
- 不改动态信息图实现；仅在回执注明它是下一规划项。
- 不删除断言、不增加 skip、不提交。

## 验证与回执

运行相关前端测试及 `npm run build`。回执写入
`docs/workmates/receipts/WEB-LOCAL-001.md`，必须列出：真实访问路径、可见交互、API 调用、测试输出、是否存在后端缺口。
