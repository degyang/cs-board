Both fail: `assert 7 == 6` — `/api/v1/services` returns 7 items instead of expected 6.

## Root Cause (proven)

The extra service is `mock-llm` (`capability: text_generation`, `adapter_type: openai_compatible`).

**Source**: `~/.csboard/settings/services/mock-llm.json` — a stale development artifact in the user's home directory.

**Mechanism** (in scope file `webapp/mountain_server.py`):

1. Module-level `app = _create_module_app()` (line 300) calls `create_app()` with no arguments → uses `_DEFAULT_DATA_DIR` = `~/.csboard`.
2. `create_app` calls `_cache_seed_template(effective_data_dir)` (line 147), which snapshots `~/.csboard/settings/services/` into a process-global `_SEED_TEMPLATE_DIR`.
3. All subsequent `create_app(tmp_path)` calls (including tests) hit `_try_populate_from_seed_cache` and hardlink from this polluted cache — receiving 7 service files instead of 6.

**Proof** (isolated tmp, no cache):

```python
import webapp.mountain_server as ms
ms._SEED_TEMPLATE_DIR = None  # reset cache
ms._SEED_TEMPLATE_TDIR = None
tmp = Path(tempfile.mkdtemp())
client = TestClient(ms.create_app(tmp))
# → 6 services, no mock-llm ✓
```

**Contrast** (cache populated from `~/.csboard`):

```python
# After import, SEED_TEMPLATE_DIR is set from ~/.csboard
# → 7 services, includes mock-llm ✗
```
